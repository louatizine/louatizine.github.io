Madame, Monsieur,

Un client qui n’a plus le temps de gérer ses certifications usine par usine, des équipes qui tapent encore les factures à la main : c’est à partir de ça que je construis. Pas à partir d’une techno. Chez Viveris, vous cherchez des développeurs Full Stack capables d’analyser un besoin, de poser l’architecture, de livrer, puis de faire tenir l’application. C’est mon quotidien depuis plus d’un an — et c’est pour ça que je vous écris.

Chez Dynamix Services, j’ai défini l’architecture technique d’un Quality Portal en C# .NET / Blazor pour un contexte industrie multi-sites : rôles, documents, alertes d’expiration, vraiment utilisé. En parallèle, j’ai développé une plateforme RH / ERP en React et Node.js, avec SQL Server, pour plus de 50 utilisateurs. Un pipeline n8n + OCR a fait baisser la saisie manuelle de 40 %. Avant ça, stage Full Stack (stocks temps réel, API JWT, Docker) puis un projet mobile branché sur un back-end Java Spring Boot. Je sais passer d’un sujet à l’autre sans tout casser.

Vous mentionnez PHP, Angular, Vue ou Oracle selon les missions. Je ne les ai pas en production, et je ne vais pas les coller sur le CV pour faire joli. En revanche j’ai déjà le socle que vous citez — C# .NET, Java, Node.js, React, JavaScript, SQL Server, MySQL — et l’habitude de monter une stack nouvelle dès que le projet l’exige. Vos formations et communautés techniques, c’est exactement le cadre dans lequel je veux le faire.

Je suis diplômé d’un Bac +5 en génie informatique (2026). Je vis encore à Bizerte. Je parle français couramment, et je suis prêt à m’installer en France dès qu’une mission démarre — deux jours de télétravail compris. Le CV est joint. Si vous voulez voir le code, mon portfolio et GitHub sont là.

Je peux me rendre disponible rapidement, en visio d’abord, sur site ensuite.
