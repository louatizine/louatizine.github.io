Depuis juin 2024, je développe un ERP en C# .NET. J’ai aussi livré des modules métier RH (congés, flotte, licences) avec les gens qui les mettent en production dans leur contexte. C’est exactement le geste que vous décrivez : concevoir, développer, puis coller avec les filiales.

Deux ans d’applications web, dont le cœur en C# et .NET. DevOps et clean code au quotidien (Azure DevOps, revues, CI/CD). CSS et stack web à côté (React, HTML). Bac +5, anglais technique correct. Je n’ai pas encore votre framework groupe : je l’apprendrai. En revanche je sais déjà entrer dans un socle existant sans tout casser.

Satisfaction client, relations propres, envie de progresser : ce n’est pas du slogan chez moi. Si le premier échange RH a lieu sous dix jours, je suis joignable.
